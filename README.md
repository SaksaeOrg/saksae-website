# saksae-website

Marketing site for [saksae.com](https://saksae.com), deployed via GitHub Pages.
Native HTML + Tailwind + a little vanilla JS. No framework, no runtime
dependencies.

| Where | What |
| --- | --- |
| [`SPEC.md`](SPEC.md) | What the product is, what the page says, the design system, and what is still placeholder content. Read this first. |
| `static/` | **The site.** Edit here. Build and i18n mechanics in [`static/README.md`](static/README.md). |
| `docs/` | Build output, served by GitHub Pages. Generated by `npm run deploy` — don't edit by hand. |

The site ships in four languages — `/`, `/en/`, `/vi/`, `/th/` — generated at
deploy time from the French source.

```sh
cd static
npm install
npm run dev        # watch css
npm run serve      # http://localhost:8080
npm run deploy     # publish into ../docs
```
