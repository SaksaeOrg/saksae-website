# saksae-website

Marketing site for [saksae.com](https://saksae.com), deployed via GitHub Pages.

| Directory | What it is |
| --- | --- |
| `static/` | **The site.** Native HTML + Tailwind + vanilla JS, no framework. See [`static/README.md`](static/README.md). |
| `docs/` | Build output, served by GitHub Pages. Generated by `cd static && npm run deploy` — don't edit by hand. |
| `frontend/` | The retired React (CRA + craco) app, kept for reference. No longer builds into `docs/`. |

```sh
cd static
npm install
npm run dev        # watch css
npm run serve      # http://localhost:8080
npm run deploy     # publish into ../docs
```
